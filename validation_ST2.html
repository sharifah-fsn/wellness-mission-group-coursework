Splash Screen validation report

The splash screen was designed to create a strong first impression while smoothly introducing the website's purpose and identity. Semantic HTML elements such as main and section were used to organise content clearly, improving both readability and maintainability. CSS was applied to create a visually appealing layout, including a full-screen background image, a dark overlay for better text contrast, and a simple loader animation to enhance the user experience. JavaScript was used to implement a dynamic countdown timer and a skip button, giving users control over navigation. The automatic redirect using the meta tag ensures a seamless transition to the home page. Accessibility was considered through proper heading structure, readable text contrast, and descriptive alt text for images. Overall, the splash screen effectively combines design, functionality, and usability to provide an engaging introduction to the website.

Action Impact Simulator validation report

The Action Impact Simulator was designed to provide an interactive and engaging way for users to understand how small lifestyle choices can contribute to better health. The use of semantic HTML ensured a clear structure, while embedded CSS allowed for customised styling without affecting the global design. JavaScript was effectively used to handle user interactions, including selecting actions, calculating total impact points, and dynamically updating feedback and background visuals. The feature enhances user engagement by providing immediate visual and textual feedback based on their choices. Additionally, accessibility was considered through meaningful alt text and clear visual indicators for selected actions. Overall, the simulator successfully combines design and functionality to create an intuitive and informative user experience.
