Home page

Technical Description

The home page was created using HTML to structure the content and CSS to control the appearance and layout. Semantic HTML tags such as <header>, <nav>, <footer> were used to organize the page into clear sections. The <header> contains the website logo title and navigation bar,for users the move between pages. The main section contains the slideshow And content cards, Images are included With alternative text. Properties as flex were used To align elements while padding and margin improved visual structure. <hover> are used For interactive effects. <Colors>, <fonts> and background tags were defined in CSS To maintain consistent visual theme that matches the concept of health and well being Flexbox is used in elements such as the header and card container to align items and distribute space evenly, while CSS Grid is used in the interactive gallery to create a responsive layout where gallery cards automatically adjust to different screen sizes using grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)). Hover effects such as image scaling (transform: scale) and brightness adjustments were implemented to provide visual feedback and make the interactive gallery more engaging for users.

Accessibility

Accessibility was considered to ensure that the Website can be used By wide range of Users. Semantic elements were used to navigate the content easily. Headings such as <h1> and <h2> were used in a logical order To organize information and improve readability. Navigation links were designed to be simple and clearly visible. These techniques help make the website more access and user friendly

Gallery Page

Technical Description

The main structure includes <header>, <nav> and <footer> To create a Clear and accessible layout. Each gallery item was created using a <div> Container that includes <img> Tag and heading to display the image and its title. Styling properties such as flex and gap were used for responsive layout. Transition were applied to improve smooth hover effect. The model pop up was styled using position,background colour and display properties so that the enlarged image and description appear clearly above the page content. These techniques help create a visually organized gallery. Styling decisions were made to create a visually appealing and interactive design while keeping the layout consistent with the rest of the website. Images are styled using object-fit: cover to ensure they fill the card without distortion, and border-radius is used to create smooth rounded corners.

Accessibility

A logical HTML structure was created using Semantec elements such as <header> ,<nav> and <footer>. Headings were used to clearly label each gallery item helping users quickly understand the content. The pop-up includes a visible close button so users can easily exit the enlarged view. The ability to change font and color was used to improve readability. These techniques have made the gallery page easier to navigate and access.

Challenges and Lessons Learned

During the implementation process several challenges were encountered while developing the web pages. One difficulty was assuring that the lay out and styling remained Consistent across different pages. Especially when using a shared global CSS. This was resolved by organizing the CSS and agreeing on the overall website style and visual design collaboratively with all team members. Another challenge Was applying different to specifics parts without affecting other elements. This issue was resolved by using more specific CSS selector Such as (ex : main section img) Instead of using styling globally. Through solving this challenge, I learned the importance of writing well-structured and specific CSS rules, understanding how CSS selectors work, and testing styles carefully to ensure that changes only apply to the intended parts of the webpage.

Compliance

The web pages were developed while considering basic Janet web publication regulations related to responsible and appropriate online content. All information included on the pages is educational and related to Sustainable Development Goal 3 - Good Health and Well-Being, which ensures the content is appropriate and does not contain offensive, misleading, or harmful material. Images used on the website were taken from free image sources and are used only for educational purposes, helping to respect copyright and intellectual property guidelines.

Clear navigation, readable text, and properly structured HTML were used to make the website accessible and user-friendly. By ensuring that the content is respectful, educational, and properly sourced, the website follows the general principles of Janet regulations for safe and responsible web page publication.
