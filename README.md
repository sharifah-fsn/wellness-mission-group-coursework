A first-year university group coursework project focused on creating a responsive wellness website using HTML, CSS, and JavaScript.
# Wellness Mission — Group Coursework

**Wellness Mission** is a group web development project designed around the theme of health and wellness. The website was developed as part of our first-year university coursework, with different members contributing to different sections and functionalities.

## Technologies Used

* HTML
* CSS
* JavaScript

## My Contributions

As a member of the development team, I was responsible for:

### Sitemap

* Designed and implemented the website sitemap.
* Added links to allow users to navigate and redirect to the relevant pages of the website.

### User Profile

* Designed and developed the user profile section.
* Implemented JavaScript functionality to make the user profile interactive.
* Worked on the structure and presentation of the profile information.

## Key Features

* Interactive user profile
* Website sitemap with navigation links
* Responsive web design
* JavaScript-based functionality
* Multiple interconnected website pages

## What I Learned

Through this project, I gained practical experience in:

* Structuring webpages using HTML
* Styling webpages using CSS
* Implementing JavaScript functionality
* Creating navigation between webpages
* Working on a website as part of a development team
* Applying web development concepts to a larger project

## Group Project

This website was developed collaboratively as part of our first-year university coursework. Each member was responsible for different sections and components of the website.
