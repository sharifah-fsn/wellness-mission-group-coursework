User Profile


Technical Description

The User Profile page was developed using HTML, CSS, and JavaScript to ensure clear structure, interactivity, and standards compliance. HTML was used to organise the content into well-defined sections, ensuring all visible information is readable and logically structured. Semantic elements such as `section` were used to separate different profile areas, while h2 and h3 headings provide a clear content hierarchy. Paragraph p elements were used for descriptive text, and div containers were used to group related components such as profile steps and progress indicators.

CSS was applied to enhance layout, readability, and visual clarity. The use of display: flex enabled a structured step-by-step layout, while margin and padding ensured consistent spacing between elements. Typography properties such as font-family, font-size, and color were used to improve readability and maintain visual consistency. Hover effects were applied to interactive elements such as buttons to provide visual feedback and improve user experience.

JavaScript was used to implement interactivity through a series of prompt-based inputs, allowing users to progressively enter their profile information. Clear instructions are provided at each step, and feedback messages guide the user throughout the process. The collected data is dynamically displayed on the page, initially hidden and revealed upon completion, creating a more engaging and guided interaction. The page was tested using HTML validation tools to ensure it conforms to web standards, with all elements properly structured and free of syntax errors. This ensures compatibility across browsers and adherence to accessibility and quality requirements.


Accessibility

Accessibility was addressed by ensuring all text content is readable and structured with semantic headings. All input prompts are accessible using the keyboard, and progress updates appear visually on the page so that screen readers can detect changes. Tab Navigation has also been enabled to increase accessibility.

Sitemap


Technical Description

The Sitemap page was implemented using SVG to visually represent the hierarchical structure of the website. Each page is represented as a node using rect elements, with corresponding text elements used for clear labeling. Relationships between pages are illustrated using line elements, providing a clear and logical representation of navigation flow.

CSS was applied to enhance visual clarity and user interaction. Different color schemes were used to distinguish between parent, child, and sub-child nodes, improving readability and structure recognition. Hover effects and focus outlines were added to interactive elements to provide visual feedback and support accessibility.

Each node was wrapped within "a" elements to enable navigation, allowing users to click on any section of the sitemap and be directed to the corresponding page. All links were implemented using the agreed file names and folder structure to ensure consistency and proper functionality across the website. The page is integrated with the shared navigation bar, where it is correctly highlighted as the active page using CSS to indicate the current location within the site.

Finally, the Sitemap page was tested using HTML validation tools to ensure it complies with web standards. All elements are properly structured, and no validation errors are present, ensuring cross-browser compatibility and adherence to best practices.


Accessibility

Accessibility was implemented by adding title tags inside each g group for screen readers, using tabindex="0"to make nodes keyboard-focusable, and adding visible focus styles so users can navigate using Tab and see which node is active.

Content Page


Technical Description

The Content Page was developed using HTML and CSS to ensure a clear structure, readability, and accessibility. HTML was used to organise content into well-defined sections, providing a logical and easy-to-follow structure. Semantic section elements were used to group related content, while h2 and h3 headings establish a clear hierarchy. Paragraph p elements were used for explanatory text, and img elements were included to support the content visually. All images were provided with meaningful alt attributes to ensure accessibility for users relying on screen readers.

CSS was applied to enhance readability and layout. Properties such as margin and padding were used to create consistent spacing, while font-family, font-size, and color improve text clarity. The layout was designed using flexible widths and responsive techniques to ensure the page remains readable across different screen sizes and devices.

Accessibility principles were considered throughout the design. Clear sectioning, readable text contrast, and descriptive alternative text for images ensure the content is accessible to a wide range of users. Finally, the Content Page was tested using HTML validation tools to ensure it complies with web standards. All elements are correctly structured and free of errors, ensuring compatibility, accessibility, and adherence to best practices.


Accessibility

Accessibility is ensured by including alt text for images, using semantic headings for content structure, and ensuring contrast between text and background.

Compliance


The web pages were developed in accordance with Janet's regulations, focusing on acceptable use, data protection, security, and accessibility. The content follows the Janet Acceptable Use Policy (AUP) by ensuring all material is appropriate, ethical, and created for educational purposes. No harmful or misleading content is included.

In terms of data protection, the website does not collect or store personal data. The User Profile page uses JavaScript prompts only for temporary interaction, ensuring compliance with GDPR principles such as data minimisation. Basic security practices were followed by avoiding external vulnerabilities and using only HTML, CSS, and JavaScript without any malicious or unauthorised functionality, aligning with the Computer Misuse Act 1990.

Accessibility was considered by using semantic HTML structure, clear headings, readable text, and meaningful alt text for images, following WCAG guidelines. The Sitemap also improves navigation and usability. Finally, all pages were validated against HTML standards to ensure proper structure, reliability, and compliance with best practices. Overall, the website demonstrates adherence to Janet compliance principles in a simple and appropriate manner for a student project.
