Feedback Page


Technical Description

The Feedback page was developed using HTML and CSS to create a clear, interactive, and user-friendly page. HTML was used to organise the page into logical sections including the programme information area, the reviews area, and the feedback form. Semantic elements such as header, main, section, form, fieldset, label, input, textarea, and select were used to give the page a meaningful structure.

CSS was used to style the scrollable programme section, cards, form layout, and buttons. Grid layout was used to arrange programme cards, while spacing, borders, shadows, and rounded corners were used to improve readability and visual consistency. I relied mainly on the shared global CSS for common styling and only used page-specific embedded CSS for features unique to the Feedback page such as the scrollable information section, the filter box, and form-specific styling.

This page also followed the agreed team file naming and shared design structure, with the Feedback page shown as the active page in navigation when visited.


Accessibility

Accessibility was considered by using clear labels for all form elements, readable text contrast, structured headings, and logical grouping with fieldsets and legends. Buttons and controls are visible and easy to use, while images include descriptive alternative text. The scrollable information area allows users to browse content without overwhelming the page layout.

Team Page


Technical Description

The Team page was created using HTML and CSS to present all group members in a structured and visually consistent format. HTML was used to organise the content into member cards containing names, roles, and profile links. Headings and grouped sections were used to keep the layout clear and easy to navigate.

CSS styling focused on card-based presentation, spacing, alignment, hover effects, and visual consistency with the website theme. The shared global stylesheet provided the main look and feel, while page-specific adjustments were used only where necessary to improve alignment and responsiveness. Card-based styling helps present each team member clearly and supports the shared design system.

The Team page also links correctly to the rest of the website using the agreed folder structure and file names, and follows the common template with header, navigation bar, main content, and footer.


Accessibility

Accessibility was supported through meaningful text structure, clear headings, readable contrast, and descriptive alternative text for any team images used. Interactive links are visually distinct and easy to access. Consistent layout and spacing improve usability for a wide range of users.

Content Page


Technical Description

My content page, content_ST3.html, was developed using HTML and CSS to present information about physical activity and fitness in a structured and readable way. The page uses semantic sections for each major topic, including the benefits of exercise, types of physical activities, daily fitness routine, sedentary lifestyle risks, and references. Images were added to support the written content and all images include alternative text.

The page was built using the shared template and shared global CSS as required. I used only minimal embedded CSS to adjust layout issues specific to the page, such as list styling, image sizing, section width, and spacing. This helped preserve consistency with the group website while still making the page readable and user-friendly.

Internal anchor links were used at the top of the page to allow users to jump directly to content sections. Navigation links were also adjusted to use the agreed file names and the content page displays itself as the active page.


Accessibility

Accessibility was addressed by using semantic sectioning, meaningful heading levels, readable text contrast, and descriptive alt text. The layout is clear and predictable, and internal navigation helps users move quickly through content. The design avoids unnecessary complexity and supports both readability and inclusivity.

Challenges and Lessons Learned


One of the main challenges I faced was combining the shared global CSS with page-specific styling without breaking the layout. At first, some content overflowed its containers and some images appeared too large or were cropped in an unfriendly way. I solved these issues by reducing page-specific CSS, relying more on the shared styles, and only overriding what was necessary.

Another challenge was keeping the pages visually consistent while still satisfying the unique requirements of each page. Through this process I learned the importance of planning structure first, testing each page carefully, and validating HTML regularly so that design and technical correctness improve together.

Compliance


The pages I created were designed in line with responsible and ethical web publishing principles. Content was written for educational purposes and does not include misleading, harmful, or inappropriate material. External resources such as information sources and images are acknowledged in the references section, supporting academic integrity and responsible reuse of content.

Accessibility was considered through semantic HTML, heading structure, alternative text for images, and readable colour contrast. Navigation is consistent and clear across pages, supporting usability. The pages also avoid collecting or storing unnecessary personal data, and the Feedback page form was created for coursework interaction only. Overall, the work demonstrates an honest and realistic understanding of compliance, accessibility, and professional web publishing practice.
